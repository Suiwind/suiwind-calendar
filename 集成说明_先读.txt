苏伊温德日历 V2.0 · 本地私密文件说明（勿上传至公开 GitHub 仓库）

本文件夹内共有两类工具：

1. 我的私密课表_站内导入用.json
   - 包含您原本硬编码在旧版网页源码中的 11 门个人课程、任课老师、教室及早/晚自习规则。
   - V2.0 已将这些隐私信息从公网部署源码中彻底剥离。
   - 使用方法：把「网站部署文件」上传到 GitHub Pages 后，打开网站 -> 右侧边栏「今日行动」-> 每日课表 -> 点击「导入私密课表」选择本 JSON 文件即可。数据仅保存在您的浏览器本地和私有 Supabase 账号中。

2. 八字合盘 V5.0 原版引擎接入
   - 方式 A（最省事）：直接部署「网站部署文件」，打开网站后点右上角「⋯ 更多」->「八字合盘 V5.0」->「导入 V5 原版 HTML」，选择您本地的原版文件即可（存入浏览器 IndexedDB，下次免导）。
   - 方式 B（全设备免导）：在命令行执行：
     python 生成含原版引擎的发布包.py /路径/合盘随身工具_V5.0_纪录更新版.html
     然后将生成的 ZIP 解压覆盖到网站根目录即可。
