苏伊温德日历 V1.7.3 +「八字合盘」V5.0 接入包

现状：站内导航、响应式合盘面板、原版HTML导入/浏览器本地保存、纪录分数对照、尝试调用原版「填入对比」以及差分计算已接入。

重要限制：本次系统未能成功读取你上传的 V5 原始 HTML 文件（尽管附件已显示）。为了不篡改或伪造评分引擎，此发布包内暂时不含 V5 核心算法源文件。五条原始分数的回归测试尚未完成。并非最终经过验证的完整版。

使用办法（任选一种）：
A. 不修改ZIP：部署本ZIP后，点击页面顶部「八字合盘」>「导入 V5 原版 HTML」，选择原始HTML文件。此浏览器记住它，下次使用不需重导；其他设备需要各自导入。适合先试用。
B. 正式部署：把原来的 V5 HTML 重命名为 bazi-hepan-v5.html，和 index.html 放在 GitHub Pages 根目录，所有设备就能直接用，原文件的字节不会经过改写。可用随包的 Python 脚本自动重新打包。

不会覆盖原有 Supabase 云同步数据。本次没有修改日历主脚本及云同步键。原版 HTML 的实际计算逻辑保持在原 HTML 内，外部容器不产生分数，也不提供评分 API。

右侧五条纪录分数为用户给出的原始数值；出生日期、原纪录填入控件和本次分数自动识别需要从 V5 原版 HTML 取得。因为未能检查原版 DOM，页面提供手动计算差距的兜底入口，无法保证所有原版按钮都能被外部面板自动点击。你可以在原版页面里使用其原有的完整「填入对比」功能。

请勿把这个接入预览包误认为算法核验通过的正式发布版。
