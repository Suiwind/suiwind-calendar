# 苏伊温德日历 V4.1 · 双端个人工作台（功能开发版）

在 V3.5 时令墨本版及 V4.0 工作台上增量开发。原日历、每日一句、课表、任务、每日复盘、专转本学习中心、周月复盘、八字 V6.1、纪念日、云同步、备份和 AI 设置继续保留。本版按用户最新要求取消贴图工具入口及跨源消息桥，替换为居家健身；不会删除本机曾经保存的贴图配置。无新增前端框架或运行依赖。

## 升级与运行

1. **先在当前站点导出 JSON 备份，保留原部署包和浏览器数据。** AI Key、八字自定义 HTML/纪录等沿用原本机存储策略，不包含在业务 JSON 中，请妥善保存。勿把真实 Key、备份 JSON、私密记录提交到公开 GitHub。
2. 解压 ZIP，覆盖原静态网站根目录（包含 `.nojekyll` 与 `icons/`）。保持同一协议、域名、端口，才能直接读取已有 localStorage 与 IndexedDB。不同 origin 需自行通过 JSON 或云同步迁移；不要清除站点数据。GitHub Pages 无需构建。
3. 本地运行：`python -m http.server 8000`，访问 `http://127.0.0.1:8000/`。若有原地址，使用原端口以保留原地址下的数据。旧 `workshop-ai-client.js` 可从部署目录移除（V4.1 不引用），但不要删除 `zx_workshopTools` 存储键。
4. 若仍显示旧版，关闭旧标签页后刷新，使用原更新提示；不要清除存储。所有设备升级后再同步。首次升级建议使用复制的备份与测试账号验收。

## 居家睡前健身

内置来源：用户上传的《居家睡前健身计划（四色弹力带 + 零地面版）》。保留三日时间、15 个核心动作、默认用带、目标次数、休息时间、热身及放松提示；未把文档中的私人课表/兼职动线或完整 DOCX 打包进源码。训练建议仅供参考，按身体状态选择阻力、动作幅度与休息时长，不强求最重弹力带或固定时限。

| 星期 | 训练方案 | 原时间 |
|---|---|---|
| 周二 | A 上肢推拉 + 站姿核心 | 21:05–21:30 |
| 周五 | B 下肢力量 | 21:05–21:30 |
| 周日 | C 全身轻量综合 | 21:00–21:25 |

- 使用北京时间的日期和周一至周日周区间，与原学习系统一致。训练日自动选 A/B/C，休息日可自行选择补练。未来日期仅预览。每日期一条记录；删除需确认。
- 默认 2 组（前两周建议），进阶可手动选 3 组；原固定两组的动作仍只显示两组。建档后方案和组数固定，避免无意覆盖记录；如需改方案，先保留原记录或确认删除后重建。
- 建立记录后，逐组勾选，实际阻力及实际次数/秒数可另填；热身、放松、训练备注均可记录。训练计时与休息倒计时采用绝对时间戳，刷新或切换模块不会重置；自动休息默认取动作区间上限，可选 45/60/90 秒或主动结束。计时仅在页面显示时刷新显示值，不每秒写本地或云端。
- 训练计时需手动开始/暂停，含休息时间；长时间离开后应暂停或手动修正分钟数（支持补记过去的用时，最大 1440 分钟）。仅今日可启动实时计时，历史日仍可暂停遗留运行中的计时。未结束不算完整训练。点结束训练后按已勾组数标记完整/部分/跳过；不强迫补练。完整/部分记录均可重新打开修正。
- 日历训练标记与所选日入口、周训练总览、历史、原周月复盘统计与 Markdown 导出均自动读取同一份记录，不制造重复任务，不计入学习计时。原 AI 周月复盘若主动调用，会带训练汇总数字，不包含健身备注或逐组明细。
- 训练时间不是系统通知；不保证浏览器关闭、锁屏时触发声音或推送。本版没有自动排课、强制训练提醒或 AI 自动增重。

## 小六壬

保留 V4.0 的本地六宫掌诀（起点计一）：大安→留连→速喜→赤口→小吉→空亡。当前时间使用浏览器本地 Intl 中国历法和北京时间；闰月取同名月，23:00 起子时，午夜换日。不同流派可能有其他口径。报三数与三个汉字 + 人工确认笔画数可离线计算；未引入完整汉字笔画库。AI 仅负责解释已确定的三宫与所问事项，复用现有配置，不算历法。卦例可保存、查看和删除；民俗参考不用于重大决策。

## 数据、云同步与兼容

- 原 `zx_*`、八字本机键和 IndexedDB 不改名、不清理。JSON 仍为 `version:30`；`calendar_state(user_id,payload,updated_at)` 表结构不变。新增 `zx_fitnessState` ↔ `payload.fitnessState`，沿用 `zx_liurenHistory` ↔ `payload.liurenHistory`。旧 JSON 缺少扩展字段时保留本机对应记录；若显式包含有效字段，则按用户确认的备份恢复。健身记录在应用前进行版本与字段校验，拒绝格式错误的备份。
- 保存训练即时更新本机并按现有云同步调度（登录且无冲突后），未登录时仅本机。云上传保留未知远端字段；对于从未初始化的本机扩展键，保留并载入有效的远端小六壬/健身字段，防止旧端升级后的空默认值覆盖。对已经存在的本机字段仍按用户选定方向整包覆盖，不自动合并训练日。
- 保留 V4.0 覆盖前快照、恢复写入失败尽力回滚、云端时间戳检查与条件 PATCH/INSERT。原版本整包上传仍可能删掉新字段，因此不要混用新旧客户端。不同设备同时修改同一份数据仍需手动处理冲突；同一浏览器多标签同步写入亦非事务数据库，建议不要同时编辑同日记录。
- AI API Key、主题、旧贴图配置、八字原有本机记录按原本机策略保存。真实 Supabase、AI、IndexedDB 及 PWA 网络环境未在此执行环境联调。
