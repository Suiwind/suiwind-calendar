## V1.7.0 更新摘要

- **快速记录**：首页新增一键入口，减少“为了记一件事要翻很多层”的摩擦，可快速开始学习计时、进入质量记录、生活记录与项目记录。
- **自适应节奏建议**：综合最近学习投入、睡眠、学习质量与当前日期状态，给出“正常推进 / 降负荷 / 以复习为主 / 优先恢复”等建议。它只提供建议，不会擅自修改正式计划，也不会制造学习债。
- **项目模式**：新增竞赛项目、长期项目、求职项目、个人项目。支持截止日期、里程碑、投入记录与备注；项目投入默认不计入专转本核心有效时长，避免“做 PPT 也算备考小时”。
- **自动周报 / 月报**：自动汇总核心有效时长、三科投入、延迟提取、错误率变化、睡眠、生活记录与项目投入，并给出一条下一步建议。报告强调趋势和瓶颈，不制造排名。
- **历史搜索**：可在长期积累的数据中检索学习记录、质量记录、项目和生活备注，方便以后回看“我什么时候学过 / 卡在哪里 / 为什么那个月状态变差”。
- **生活记录（非 KPI）**：可轻量记录运动/活动、户外、社交/约会、兴趣娱乐与可选幸福感。它不会参与 S/A/B/C，不设连续打卡，不因为空白变红。
- **同步差异比较**：云同步面板新增本地/云端数据数量与修改时间比较。学习计时、睡眠、学习质量、项目和生活记录采用可合并账本逻辑；普通任务和日历结构仍由用户决定使用哪一端，避免“自动聪明”造成误覆盖。
- **滚动历史与撤销**：内部安全快照从 3 份扩展到最多 7 份；重大导入/下载前自动留档，日常修改约每 30 分钟最多创建一份滚动历史，可用于撤销与恢复。
- **数据兼容**：V1.7.0 继续沿用 V1.6.0 / V1.5.9 的 `learningState`，仅增量新增 `v170` 状态；Supabase `calendar_state` 表结构不变；V1.5.7 睡眠按日期 + `updatedAt` 合并和学习计时唯一 ID 合并继续保留。
- Service Worker 缓存升级为 `suiwind-calendar-v170`。

> V1.7.0 的原则：**工具负责降低摩擦、发现趋势和保护数据；人生不被 KPI 化，建议不替你做决定。**

## V1.5.3 核心更新

### 1. 今日学习

- 学习管理的首页命名为 **今日学习**，把当天最需要处理的学习、复习、考试倒计时和学习计时集中到一页。
- 新增 **高能量 / 标准 / 低负荷** 三种学习能量模式。
- 能量模式只调整“今天建议做到什么程度”，不会篡改正式学习进度。
- 军训保护期、缓冲日和周一英语总复习规则继续生效。

### 2. 科学学习计时

- 每科都可独立点击 **开始学习 → 结束学习**，支持：英语、财经、高数、其他。
- 只统计真实“专注阶段”的时间，休息时间不计入学习时长。
- 标准 / 高能量模式采用 **50 分钟专注 + 10 分钟离屏休息**；连续两轮后建议 **20 分钟长休息**。
- 低负荷模式采用 **25 分钟专注 + 5 分钟休息**；连续两轮后建议 **15 分钟长休息**。
- 专注阶段每 20 分钟提示一次 **20-20-20 护眼**：看约 6 米外至少 20 秒。
- 页面关闭后重新打开，当前计时阶段仍可恢复。
- 学习时间按科目、今天、本周、本月分别统计，并保留最近学习记录。

> 说明：不存在适用于所有人的唯一“科学番茄时长”。V1.5.3 的默认设计重点是规律短休息、限制持续近距离用眼和避免疲劳累积；如果当天状态差，直接使用低负荷模式。

### 3. 间隔复习

- 财经、高数、四级技巧课完成正式学习后，自动生成 **+1 / +3 / +7 / +14 / +30 天**复习任务。
- 到期未复习不会消失，也不会制造学习进度“失败”，而是进入待复习队列。
- 英语单词不重复套用这套算法，继续使用已经确定的：**早上复习昨日 + 晚上复习昨日 + 周一一周总复习**。
- 可分别关闭财经 / 高数 / 四级技巧的自动间隔复习。

### 4. 年度路线图

- 新增 **2026—2029 年度路线图**。
- 路线图直接读取“我的倒数日”，因此日期只需要修改一次，今日学习、路线图和月历会一起更新。
- 当前阶段主题：
  - 2026：基础打底年
  - 2027：能力提升年
  - 2028：强化沉淀年
  - 2029：冲刺应考年

### 5. 倒数日完全可编辑

- 取消原来的“英语三级 B / 2029 江苏专转本系统固定节点”。
- **所有考试 / 考证节点现在都可以编辑、修改日期、修改名称、修改备注，也可以删除。**
- 新增可选“结束日期”，支持记录考试窗口。
- 从 V1.4.2 升级时，会一次性迁移为可编辑节点；之后用户删除的节点不会再次自动生成。
- 当前会预置并全部允许编辑：

  - 2026-12-13 英语三级 B
  - 2027-03-27—03-29 计算机二级 WPS（预计）
  - 2027-06-12 英语四级 CET4（预计）
  - 2027-12-11 英语六级 CET6（预计）
  - 2029-03-20—03-31 江苏专转本预计窗口

### 6. 原 V1.4 动态计划继续保留

- 英语第一轮 45 Lesson：周一总复习，周二—周日默认 1 Lesson；短课可连续完成多个，后续自动前移。
- 第一轮 45/45 后才开启独立第二轮与 38 节四级技巧课。
- 财经继续采用“会计优先闭环 → 财管闭环 → 经济学闭环 → 三科收官”的实际执行顺序。
- 高数继续保留机构 48 天完整计划。
- 缓冲日 / 今天很忙 / 自主学习记录 / 军训保护期继续保留。

## 暂缓但保留在后续路线的想法

这几项不是删除，而是刻意等真实学习数据积累后再做：

- **薄弱点 / 错题系统**：现在知识点和错题数据还少，过早搭建会变成空壳；等开始系统做题后再接入。
- **更高级的自适应学习推荐**：以后可根据学习时长、完成速度、能量模式、延期次数和复习完成情况，动态调整下一周负荷。
- **“人生事件”2.0**：暂不做普通事件清单。未来如果开发，方向会是把学习、证书、旅行、健康、成长目标做成一条可缩放的人生时间轴，而不是再造一个普通倒数日列表。

## V1.5.5 本次优化

- **计时入口前置**：学习管理各页顶部常驻“学习计时”快捷条；计时中可直接看到科目与累计时长，并一键结束保存。
- **按钮确认感**：全部按钮加入按压缩放/回弹；手机默认开启轻触震动；点击音效可选、默认关闭，适合图书馆和晚自习。
- **能量模式真正分级**：标准模式只做当天计划量；高能量模式完成核心任务后再给一个“可选加量”；低负荷模式只保留核心内容。加量不形成欠账。
- **复习预算制**：默认每天最多 15 分钟，按约 5 分钟/项推送最值得复习的内容；旧任务留队列、不再无限红色催债。预算可在 5—45 分钟间调整。
- **睡眠统计**：新增“睡眠”页，记录上床、估计入睡、起床、起床难度、白天困意、午睡和备注；展示近 7 天平均睡眠与阶段判断，并在学习统计页关联显示。
- **数据兼容**：睡眠、按钮反馈和复习预算都写入 `learningState`，继续沿用本地 + Supabase 云同步；旧 V1.5.4 数据可直接升级。
