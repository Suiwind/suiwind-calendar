# 苏伊温德日历 V2.0

个人日历、动态学习计划、专注计时、睡眠记录、个人成长制度与复盘系统（纯静态 PWA，零构建依赖，可直接部署至 GitHub Pages）。

## V2.0 全面优化摘要

### 1. 模块化与架构重构
- **消除双份巨型单体文件**：`index.html` 从 509 KB 精简至约 34 KB；样式独立为 `styles.css`，公开静态课程与节气数据独立为 `app-data.js`，主程序独立为 `app.js`。
- **扁平化代码逻辑**：清除了从 V1.4.2 累积到 V1.7.3 的多层同名函数覆写（`renderLearningToday`、`renderLearningEnglish`、`normalizeLearningState` 等均重构为单一清晰实现），消除重复渲染与潜在冲突。
- **按需计时**：学习计时器的每秒轮询改为仅在计时激活时启动，空闲时不占 CPU 与手机电量。

### 2. 视觉质感与交互体验
- **首屏减重**：顶部 4 项统计收敛为精致四栏指标条；本周/本月/期限概览在无待办时自动收起为精简横条，让月历与今日焦点完整落在首屏。
- **导航分级**：顶部保留「学习管理」「快速记录」双核心与常用按钮，将八字合盘、纪念日、通知开关收纳进「⋯ 更多」菜单。
- **右侧栏三页签**：将原本纵向堆叠 8 个区块的长边栏整理为「今日行动」「任务目标」「每日复盘」三页签，合并重复信息并优化按钮排版。
- **统一设计系统 + 晚自习暗色模式**：全站统一雾茶绿 + 暖纸白 Design Tokens，抬升小字可读性，并新增一键切换护眼暗色模式（燃尽图 SVG 同步自适应）。
- **学习管理 5 分组导航**：18 个功能栏目按「执行 / 三科 / 复盘 / 生活 / 规划」5 组归类展示，PC 与手机均零横滑。

### 3. Bug 修复、隐私保护与 PWA 增强
- **修复全局搜索漏搜每日复盘**：`v170SearchAll` 现正确检索每日复盘真实存储字段 `q1 / q2 / q3`，并支持点击「定位」直接跳转到对应日期与复盘页签。
- **修复系统诊断误报**：版本号与 Service Worker 缓存校验统一读取 `APP_VERSION`（`V2.0.0`）和 `APP_CACHE_TAG`（`v200`）。
- **公网源码零隐私泄露**：个人真实课表、教室与老师姓名已从公网代码移除，改为站内导入「我的私密课表_站内导入用.json」，数据仅存于本地与私有 Supabase。
- **PWA 完整化**：补齐雾茶绿专属桌面图标（`favicon.svg`、`icons/icon-192.png`、`icons/icon-512.png`、`icons/apple-touch-icon.png`）；`sw.js` 升级为 `suiwind-calendar-v200`，并在页面右下角提供「发现新版本 · 立即更新」提示条。

## 部署与数据兼容说明

- **100% 兼容 V1.x 数据**：所有 `localStorage` 键名（`zx_*`）、`learningState` 数据结构、Supabase `calendar_state` 表结构、多设备安全合并账本以及八字合盘独立 IndexedDB 容器均完全兼容，直接覆盖旧版即可无损升级。
- **部署步骤**：将 `网站部署文件/` 目录内的全部文件（含 `.nojekyll` 和 `icons/` 文件夹）上传覆盖到 GitHub Pages 仓库根目录即可。请勿上传 `本地私密文件_勿传GitHub/` 目录。
