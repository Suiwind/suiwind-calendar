# 苏伊温德日历 V3.0 · 新中式极简手账版

## 本次 V3.0 升级亮点

### 1. 视觉重构（新中式极简手账风格）
- **去边框、重留白**：保留雾茶绿 + 暖纸白与晚自习护眼暗色主题，去掉生硬的卡片套娃边框，改为柔和的色块层级与大圆角。
- **衬线体层次**：主标题、副标题「生命如暗室，不妨我明写春诗」、月份与日期大数字采用雅致衬线体。
- **清爽首屏**：砍掉顶部冗余的统计条与三栏概览，月历每格最多展示 1 个核心文字标签 + 底部极简状态点。

### 2. 功能大瘦身（删去高摩擦模块）
- 删去：月度 S/A/B/C 制度与代币、延迟提取与错误率填表、睡眠实验、生活打卡、节奏建议、独立项目模式、无法直连的假 AI 接口、重复的快速记录弹窗。
- 精简：**学习中心**从 18 个标签合并为 4 个核心标签（今日推进 / 专注计时 / 三科清单与燃尽图 / 考试倒数与路线图）。
- 升级：**八字合盘 V5.2** 直接内置并提至顶部主导航；**周/月复盘**支持一键复制纯文本发给 AI 分析或导出 Markdown。

### 3. 数据兼容与部署
- **100% 兼容 V1.x / V2.x 数据**：所有 `localStorage` 键名与 Supabase 表结构无缝兼容。
- **部署方法**：将 `网站部署文件/` 目录下的全部文件覆盖上传至 GitHub Pages 仓库根目录即可（请勿上传 `本地私密文件_勿传GitHub/`）。
