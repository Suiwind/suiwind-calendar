# 苏伊温德日历 · GitHub Pages 发布包

这是 **V1.4.0「学习管理 · 动态计划引擎」** 的 GitHub Pages 发布目录。

## V1.4.0 核心更新

- 新增顶部 **学习管理** 入口，以及右侧日期详情中的学习概览。
- 新增“动态任务队列”：提前完成会自动推进下一项；临时忙不会生成逾期红字，恢复后继续从第一项未完成内容开始。
- 新增 **缓冲日 / 今天很忙**：可为志愿、普通话考试、临时作业等现实占用留出空间。
- 新增 **自主学习记录**：军训期间学习财经或高数可以记录，但不会推进正式计划 Day。
- 2026-10-12 至 2026-10-25 设为 **军训保护期**：财经、高数正式进度冻结；10-26 起恢复正式队列。

## 英语

- 《英语四级你还在背单词吗》按 **45 个 Lesson** 建立第一轮与第二轮独立进度。
- 第一轮规则：周一一周总复习；周二至周日默认至少 1 个 Lesson，可在短课日连续完成多个 Lesson，后续队列即时前移。
- 每天可分别勾选“早上复习昨日词汇”“晚上复习昨日词汇”；周一额外勾选“一周总复习”。
- 第一轮 45/45 完成后，才解锁正式 **第二轮 0/45** 与刘晓燕《就这样过英语四级》**38 节技巧课**。
- 38 节技巧课按写作 5、翻译 4、听力 9、阅读 20 收录，并保留截图中给出的课程名称与时长。
- 英语三级 B 考试硬节点：**2026-12-13**；内容收官目标：**2026-12-10**；第一轮软目标：**2026-11-18**。
- 新增第一轮动态预测：根据实际打勾速度，估算完成日期和达到软目标所需的平均 Lesson / 学习日。

## 财经综合

- 完整收录机构 **80 天**学习计划的科目、内容和核心目标摘要。
- 保留机构原 Day 编号，同时新增独立“实际执行序号”。
- 执行顺序调整为：
  1. 会计闭环 24 天：原 Day 1-11 → 34-40 → 57-58 → 63-66
  2. 财管闭环 22 天
  3. 经济学闭环 27 天
  4. 三科收官 7 天
- 这样可优先覆盖本学期《基础会计》闭卷期末，同时不删除机构原计划中的任何一天。

## 高数

- 完整收录机构 **48 天**零基础学习计划。
- 每个 Day 保留对应视频标题、视频时长和“打铁”题号。
- 仍按机构原顺序推进，但采用动态队列：提前完成就前移，忙碌时停住，不制造逾期。

## 数据与云同步

- 学习管理数据已经纳入原有 JSON 本地备份与 Supabase `calendar_state` 云同步 payload。
- **不修改 Supabase 表结构，不需要执行新的 SQL。**
- V1.3.2 的固定设备长期登录 / refresh token 续期修复全部保留。
- PWA 缓存升级为 `suiwind-calendar-v140`。

## GitHub Pages 更新

推荐直接用完整发布包覆盖仓库根目录。若手动覆盖，至少更新：

- `index.html`
- `sw.js`
- `README.md`

`supabase-local.js`、`manifest.json`、`.nojekyll` 与 V1.3.2 兼容，也已包含在完整发布包中。

部署完成后，如果手机 PWA 仍显示旧版本，请彻底退出 PWA 后重新打开；必要时等待 GitHub Pages 发布完成后再刷新。不要主动清除网站数据，以免把本地会话和未同步数据一起清掉。
